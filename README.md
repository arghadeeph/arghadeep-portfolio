## ✨ Overview

A modern, interactive portfolio website showcasing my 10+ years of experience as a Senior Backend Engineer. Built with clean design principles, smooth animations, and a fully functional contact system.

### 🎯 Live Demo
**[👉 View Live Portfolio](https://arghadeep-portfolio.vercel.app)**

## 🌟 Features

- **🎨 Modern Dark Theme** - Easy on the eyes with accent colors
- **⚡ Interactive UI** - Smooth animations and transitions
- **📱 Fully Responsive** - Works perfectly on all devices
- **✉️ Contact Form** - Sends emails directly to my inbox
- **🖱️ Custom Cursor** - Unique interactive experience
- **✨ Particle Background** - Dynamic visual effect
- **⌨️ Typing Animation** - Dynamic role display
- **📊 Project Showcase** - 6+ featured projects with details

## 🛠️ Tech Stack

### Frontend
- **HTML5** - Semantic markup
- **CSS3** - Custom styling with variables
- **JavaScript** - Vanilla JS for interactions
- **Font Awesome** - Professional icons
- **Google Fonts** - Space Grotesk & Inter

### Backend
- **Node.js** - Server environment
- **Express** - Web framework
- **Nodemailer** - Email sending
- **Vercel Serverless** - API deployment

### DevOps & Tools
- **Git** - Version control
- **GitHub** - Code repository
- **Vercel** - Hosting & deployment
- **Environment Variables** - Secure configuration
